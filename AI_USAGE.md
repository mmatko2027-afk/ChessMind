# Використання штучного інтелекту в проєкті ChessMind

## 1. Мета використання AI

Під час розробки ChessMind штучний інтелект використовується для створення інтелектуального шахового тренера, який допомагає користувачам навчатися шахів, аналізувати партії та покращувати свої навички гри.

У проєкті передбачено використання двох основних AI-компонентів:

- Мовна модель через Gemini API — для спілкування з користувачем, пояснення шахових ситуацій, надання підказок і рекомендацій українською мовою.
- Шаховий рушій Stockfish — для аналізу шахових позицій, пошуку найкращих ходів та визначення помилок і неточностей.

## 2. Інструменти штучного інтелекту

### 2.1. Gemini API

Мовна модель використовується для:

- пояснення шахових правил;
- пояснення причин вибору певного ходу;
- надання підказок відповідно до рівня користувача;
- пояснення помилок і неточностей;
- формування рекомендацій після завершення партії;
- спілкування з користувачем природною українською мовою.

Мовна модель отримує результати шахового аналізу від Stockfish і на їх основі формує зрозумілі пояснення.

### 2.2. Stockfish

Stockfish — спеціалізований шаховий рушій, який використовується для:

- аналізу шахових позицій;
- пошуку найкращих ходів;
- оцінювання позицій;
- визначення помилок і неточностей;
- розрахунку можливих продовжень партії;
- виконання ходів комп'ютерного суперника.

Stockfish відповідає за шахові розрахунки, а не за спілкування з користувачем.

### 2.3. Інші інструменти

- python-chess — бібліотека для роботи з шаховими правилами, ходами, позиціями та файлами PGN.
- FastAPI — створення серверної частини застосунку.
- Python — основна мова програмування проєкту.
- HTML, CSS, JavaScript — створення користувацького інтерфейсу.

## 3. Розподіл відповідальності

| Компонент | Відповідальність |
|---|---|
| Звичайний програмний код | Перевірка ходів, робота з дошкою, обробка даних і керування режимами |
| Stockfish | Шаховий аналіз і пошук найкращих ходів |
| Мовна модель | Пояснення результатів аналізу та спілкування з користувачем |
| Розробник | Проєктування, написання коду, перевірка результатів і виправлення помилок |
| Користувач | Вибір рівня, виконання ходів та прийняття навчальних рекомендацій |

## 4. Використання AI під час розробки

AI-інструменти можуть використовуватися як допоміжні засоби для:

- пояснення незнайомих програмних конструкцій;
- пошуку помилок у коді;
- отримання прикладів реалізації окремих функцій;
- створення та вдосконалення документації;
- підготовки тестових прикладів;
- пояснення принципів роботи FastAPI, python-chess і Stockfish.

Усі запропоновані AI рішення перевіряються та за потреби змінюються розробником.

## 5. Обмеження використання AI

- Мовна модель не повинна самостійно вигадувати найкращі шахові ходи.
- Шахові оцінки та результати розрахунків беруться від Stockfish.
- Якщо результат шахового аналізу відсутній, мовна модель повинна повідомити про це, а не вигадувати відповідь.
- Відповіді мовної моделі можуть містити неточності, тому їх необхідно перевіряти.
- У разі недоступності Gemini API основні функції шахової дошки мають залишатися доступними.
- API-ключі не можна зберігати у відкритому вигляді в репозиторії.

## 6. Перевірка якості

Для перевірки роботи AI передбачено файл `eval/cases.json`, який містить тестові приклади.

Перевірятимуться:

- правильність пояснення шахових правил;
- відповідність пояснень рівню користувача;
- правильне використання результатів Stockfish;
- відсутність вигаданих шахових ходів та оцінок;
- зрозумілість рекомендацій;
- коректна обробка помилок і недоступності API.

## 7. Висновок

У проєкті ChessMind штучний інтелект використовується для поєднання точного шахового аналізу та зрозумілого навчального пояснення. Stockfish виконує шахові розрахунки, а мовна модель допомагає користувачеві зрозуміти їх результати. Розробник відповідає за інтеграцію компонентів, перевірку роботи системи та остаточну якість програмного продукту.
