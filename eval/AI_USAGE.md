
# AI Usage — ChessMind

## Використання штучного інтелекту

У проєкті ChessMind передбачено використання AI-помічника для навчання шахів.

На поточному етапі використовується Mock AI Provider. Він імітує роботу AI-провайдера та повертає підготовлені відповіді на запитання користувача.

## Можливості

- Пояснення правил шахів.
- Пояснення руху шахових фігур.
- Надання простих рекомендацій.
- Підготовка до майбутнього підключення справжньої AI-моделі.

## Перевірка роботи

Для перевірки передбачено такі режими:

- Звичайна відповідь.
- Затримка відповіді.
- Таймаут.
- Обмеження кількості запитів.
- Недоступність провайдера.
- Некоректна відповідь.
- Переривання потоку відповіді.

## Межі використання AI

AI-помічник призначений для пояснення шахових правил і навчання.

Перевірка правильності шахових ходів та дотримання правил гри повинна виконуватися програмним кодом або шаховим рушієм, а не лише мовною моделлю.

## Безпека

- API-ключі не зберігаються в коді.
- Для локальних налаштувань використовується файл `.env`.
- Файл `.env` не додається до Git.
- Для початкового тестування не потрібен платний AI API.
