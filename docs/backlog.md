# Backlog проєкту ChessMind

## 1. Загальна інформація

Назва проєкту: ChessMind — інтелектуальний шаховий тренер.

Тривалість розробки: 7 тижнів.

Мета: створити вебзастосунок для навчання шахів, гри проти комп'ютерного суперника та аналізу завершених партій із використанням мовної моделі та спеціалізованого шахового рушія Stockfish.

## 4. Основний результат

Після завершення семи тижнів має бути створено вебзастосунок ChessMind, який дозволяє грати в шахи, навчатися, отримувати підказки та аналізувати партії.

У проєкті використовуються два основні AI-компоненти: Stockfish для шахових розрахунків і мовна модель через Gemini API для пояснення результатів аналізу природною українською мовою.
