# Вимірювання ChessMind

## 1. Тестування реальної AI-моделі

Для перевірки реального AI-провайдера використовувалася модель
`gemini-3.1-flash-lite` через OpenAI-compatible API.

Було виконано 5 тестових запитів на шахову тематику:

1. Як ходить кінь у шахах?
2. Як ходить тура у шахах?
3. Чим відрізняється слон від коня?
4. Що таке шах у шахах?
5. Що означає мат у шахах?
