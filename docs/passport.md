# Паспорт проєкту ChessMind

## 1. Назва проєкту

**ChessMind — інтелектуальний шаховий тренер.**

## 2. Проблема

Людям, які вивчають шахи, складно самостійно аналізувати свої ходи, знаходити помилки та розуміти, як покращити гру. Звичайні шахові програми переважно показують найкращий хід, але не завжди пояснюють його зрозуміло для початківців.

ChessMind має допомогти користувачам навчатися шахів, грати проти штучного інтелекту, отримувати підказки та аналізувати власні партії.

## 3. Цільова аудиторія

- Початківці, які тільки вивчають шахи.
- Гравці середнього рівня, які хочуть покращити свої навички.
- Користувачі, які хочуть грати проти комп'ютера та аналізувати партії.

## 4. Основні можливості системи

### 4.1. Вибір рівня користувача

Перед початком роботи користувач самостійно обирає свій рівень.

Початківець:
- шахові фігури мають підписи з назвами;
- система пояснює правила та можливі ходи;
- користувач отримує підказки під час гри;
- доступні пояснення переміщення кожної фігури.
Середній рівень:
- шахові фігури відображаються без підписів;
- користувач грає самостійніше;
- за потреби може отримати підказку щодо найкращого ходу;
- система пояснює тактичні можливості та можливі помилки.
Досвідчений гравець:
- шахові фігури відображаються без підписів;
- підказки вимкнені за замовчуванням;
- доступний поглиблений аналіз шахових позицій;
- система показує неточності, помилки та сильніші альтернативи ходів;
- після завершення партії надається детальний аналіз із рекомендаціями.

Рівень можна обрати самостійно, без обов'язкового тестування.

### 4.2. Гра з AI

Користувач може одразу обрати гру проти штучного інтелекту.

Перед початком можна налаштувати рівень складності суперника. Під час гри система перевіряє правильність ходів, а після завершення партії формує аналіз.

### 4.3. Аналіз шахової партії

Після завершення гри користувач отримує:
- загальний результат партії;
- перелік помилкових і неточних ходів;
- найкращі альтернативні ходи;
- пояснення допущених помилок;
- рекомендації для покращення гри.

Також передбачається можливість завантажити раніше зіграну партію у форматі PGN для аналізу.

## 5. Основний сценарій використання

1. Користувач відкриває ChessMind.
2. Обирає свій рівень: початківець, середній або досвідчений.
3. Обирає режим роботи:
   - навчання з підказками;
   - гра проти AI;
   - аналіз завершеної партії.
4. Якщо користувач обирає навчання або гру, відкривається шахова дошка.
5. Система перевіряє допустимість кожного ходу за допомогою шахового модуля.
6. Спеціалізований шаховий рушій Stockfish аналізує позицію та визначає можливі найкращі ходи.
7. Мовна модель отримує результати шахового аналізу та формує пояснення відповідно до рівня користувача.
8. Після завершення партії система формує звіт із помилками, неточностями та рекомендаціями.
9. Користувач переглядає результати та може продовжити навчання.

## 6. Для чого використовується штучний інтелект

У проєкті використовуються два AI-компоненти з різними завданнями.

**Мовна модель (LLM) використовується для:**
- спілкування з користувачем українською мовою;
- пояснення шахових правил і ситуацій;
- пояснення причин помилкових ходів;
- формування підказок відповідно до рівня користувача;
- пояснення найкращих ходів, запропонованих шаховим рушієм;
- створення рекомендацій для покращення гри;
- формування підсумкового звіту після партії.

**Спеціалізована шахова модель (Stockfish) використовується для:**
- аналізу шахових позицій;
- визначення найкращих можливих ходів;
- оцінювання переваги білих або чорних;
- пошуку помилок і неточностей;
- розрахунку можливих продовжень партії;
- забезпечення гри проти комп'ютерного суперника.

Обидва компоненти працюють спільно: Stockfish виконує шахові розрахунки, а мовна модель пояснює їх користувачеві.

## 7. Розподіл відповідальності

**Звичайний програмний код:**
- відображення шахової дошки та фігур;
- вибір рівня користувача;
- керування режимами роботи;
- перевірка допустимості ходів;
- обробка ходів користувача;
- взаємодія із шаховим рушієм та мовною моделлю;
- збереження і завантаження партій;
- формування структури результатів аналізу.

**Спеціалізований шаховий рушій Stockfish:**
- аналіз поточної позиції;
- пошук найкращих ходів;
- оцінювання позиції;
- пошук шахових помилок і неточностей;
- розрахунок ходів комп'ютерного суперника.

**Мовна модель (LLM):**
- пояснення шахових ситуацій;
- спілкування з користувачем;
- формування підказок;
- пояснення помилок та найкращих ходів;
- створення рекомендацій;
- формування навчального звіту.

**Людина:**
- обирає рівень і режим роботи;
- самостійно виконує ходи;
- приймає рішення щодо використання підказок;
- оцінює отримані рекомендації;
- використовує результати аналізу для навчання.

## 8. Вхідні та вихідні дані

**Вхідні дані:**
- обраний рівень користувача;
- обраний режим роботи;
- ходи користувача;
- поточна шахова позиція;
- історія партії;
- PGN-файл для аналізу (за наявності);
- запитання користувача до мовної моделі.

**Вихідні дані:**
- оновлена шахова дошка;
- відповіді комп'ютерного суперника;
- оцінка шахової позиції;
- найкращі альтернативні ходи;
- список помилок та неточностей;
- пояснення мовної моделі;
- підказки відповідно до рівня користувача;
- підсумковий аналіз партії;
- рекомендації для подальшого навчання.

## 9. Технології реалізації

- Python — основна мова програмування.
- HTML, CSS, JavaScript — створення інтерфейсу та шахової дошки.
- FastAPI — розробка серверної частини та API.
- python-chess — робота з шаховими правилами, ходами та PGN-файлами.
- Stockfish — спеціалізований шаховий рушій для аналізу позицій та гри проти комп'ютера.
- Gemini API — підключення мовної моделі для спілкування та пояснень.
- RAG — використання навчальних матеріалів із шахів для надання більш змістовних відповідей.

## 10. Моделі та додаткові AI-компоненти

**Основна мовна модель: Gemini API.**

Використовується для взаємодії з користувачем, пояснення шахових ситуацій, формування підказок та навчальних рекомендацій.

**Альтернативна мовна модель: OpenAI API.**

Може бути підключена для порівняння якості відповідей або як альтернативний постачальник мовної моделі.

**Спеціалізований шаховий рушій: Stockfish.**

Використовується для точного аналізу шахових позицій, пошуку найкращих ходів, оцінювання позицій та гри проти комп'ютера.

**Додатковий AI-компонент: RAG.**

Використовується для пошуку інформації в підготовленій базі навчальних матеріалів із шахів. Знайдені матеріали можуть передаватися мовній моделі для формування відповідей.

Stockfish та мовна модель мають різні завдання і не замінюють один одного.

## 11. Обмеження та обробка помилок

- Якщо мовна модель недоступна, система повідомляє про помилку та зберігає можливість виконувати базові шахові операції.
- Якщо Stockfish не запущений, система повідомляє про недоступність шахового аналізу та гри проти комп'ютера.
- Якщо користувач виконує недопустимий хід, система його відхиляє.
- Якщо PGN-файл пошкоджений або має неправильний формат, система повідомляє про це.
- Мовна модель може неправильно пояснити шахову ситуацію, тому конкретні оцінки позицій і найкращі ходи беруться від Stockfish.
- Якість пояснень залежить від мовної моделі та переданих їй даних.
- Використання зовнішніх API може мати обмеження за кількістю запитів і вартістю.

## 12. Критерії оцінювання якості

1. Коректність шахових правил — система повинна блокувати всі недопустимі ходи.
2. Точність шахового аналізу — оцінки та найкращі ходи повинні відповідати результатам Stockfish.
3. Якість пояснень — не менше 80% перевірених пояснень мають бути зрозумілими та відповідати результатам шахового аналізу.
4. Робота рівнів — повинні коректно працювати три рівні користувача: початківець, середній та досвідчений.
5. Робота режимів — повинні функціонувати навчання з підказками, гра проти AI та аналіз завершених партій.
6. Стабільність — система повинна обробляти помилки API, некоректні файли та недоступність окремих компонентів без аварійного завершення роботи.

## 13. Ризики та витрати

- Можливі обмеження безкоштовного використання мовної моделі.
- Залежність пояснень від доступності зовнішнього API.
- Можливі помилки мовної моделі під час пояснення шахових ситуацій.
- Необхідність налаштування та інтеграції Stockfish.
- Навантаження під час аналізу складних шахових позицій.
- Витрати часу на розробку інтерфейсу, інтеграцію двох AI-компонентів та тестування.
- Можливі проблеми з передаванням даних між мовною моделлю та шаховим рушієм.

Для зменшення ризиків шахові розрахунки виконуватиме Stockfish, а мовна модель отримуватиме вже підготовлені результати для пояснення. У разі недоступності одного компонента інші базові можливості системи повинні залишатися працездатними.

## 14. Що не входить до першої версії проєкту

- Онлайн-гра між користувачами через Інтернет.
- Турнірна система та рейтинги гравців.
- Мобільний застосунок.
- Повноцінний голосовий помічник.
- Автоматичне визначення рівня користувача.
- Навчання власної мовної моделі з нуля.
- Розробка власного шахового рушія замість використання Stockfish.

## 15. Очікуваний результат

У результаті розробки буде створено вебзастосунок ChessMind — інтелектуальний шаховий тренер, який поєднуватиме мовну модель та спеціалізований шаховий рушій.

Користувач зможе самостійно обирати рівень підготовки, навчатися з підказками, грати проти комп'ютера та аналізувати завершені партії.

Шаховий рушій відповідатиме за точність розрахунків і пошук найкращих ходів, а мовна модель — за спілкування, пояснення та формування навчальних рекомендацій.

Головна мета проєкту — створити інтерактивного шахового тренера, який не просто показує правильні ходи, а й допомагає користувачеві зрозуміти шахову логіку.
Головна мета проєкту — зробити навчання шахів доступнішим, зрозумілішим та інтерактивним.
