# Паспорт проєкту ChessMind

## 1. Загальна інформація

Назва проєкту: ChessMind.

Тип проєкту: інтелектуальний шаховий помічник.

Платформа: вебзастосунок із REST API.

Мова програмування: Python.

Основний фреймворк: FastAPI.

База даних: SQLite.

AI-провайдер: Gemini через OpenAI-compatible API.

## 2. Мета проєкту

Мета ChessMind — створити інтелектуального помічника,
який допомагає користувачам вивчати шахи та отримувати
зрозумілі пояснення шахових понять і правил.

Система повинна надавати відповіді простою мовою,
враховувати переданий контекст і допомагати користувачу
краще розуміти шахову гру.

## 3. Основні функції

1. Отримання запитань користувача через REST API.
2. Пояснення шахових правил і понять.
3. Формування контексту для AI-запиту.
4. Використання різних AI-провайдерів.
5. Отримання структурованих відповідей.
6. Перевірка результату відповіді.
7. Обробка помилок AI-провайдера.
8. Облік використання токенів і вартості запитів.
9. Контроль денного бюджету та кількості AI-запитів.
10. Збереження інформації про використання AI у SQLite.

## 4. Технології

| Технологія | Призначення |
|---|---|
| Python | Основна мова програмування |
| FastAPI | Створення REST API |
| Pydantic | Перевірка та опис даних |
| SQLite | Зберігання інформації |
| Gemini | Генерація відповідей |
| OpenAI SDK | Підключення до сумісного API |
| Pytest | Автоматизоване тестування |
| JSON | Передавання структурованих даних |

## 5. Архітектура системи

Проєкт має модульну архітектуру.

Основні компоненти:

- API — приймає запити користувача.
- Service — обробляє запити на рівні сервісу.
- Orchestration — координує процес отримання відповіді.
- AI Gateway — вибирає потрібного AI-провайдера.
- Providers — реалізують роботу з різними провайдерами.
- Prompting — формує інструкції для AI.
- Context Builder — формує контекст запиту.
- Storage — працює з базою даних SQLite.

## 6. AI-провайдери

У проєкті передбачено декілька варіантів роботи:

- MockAIProvider — тестовий провайдер, який не потребує
  звернення до зовнішньої AI-моделі.
- OpenAICompatibleProvider — провайдер для роботи
  із сервісами, що підтримують OpenAI-compatible API.
- RecordedAIProvider — провайдер для використання
  збережених відповідей під час тестування.

Для перевірки реального підключення використовувалася
модель Gemini `gemini-3.1-flash-lite`.

## 7. Безпека та обмеження

Система повинна:

- зберігати API-ключ у змінних середовища;
- не виводити секретні дані в журнали;
- обробляти помилки зовнішнього AI-сервісу;
- обмежувати кількість запитів і денний бюджет;
- перевіряти структуру отриманих відповідей;
- враховувати, що відповіді AI можуть містити помилки.

ChessMind є навчальним помічником, а не шаховим
рушієм для гарантованого визначення найкращих ходів.

## 8. Критерії оцінювання

Основними критеріями якості є:

1. Коректна робота REST API.
2. Успішне підключення AI-провайдера.
3. Правильна обробка помилок.
4. Перевірка структури відповідей.
5. Контроль використання AI-ресурсів.
6. Наявність автоматизованих тестів.
7. Вимірювання часу відповіді та кількості токенів.

## 9. Поточний стан

Реалізовано основні компоненти API, систему AI-провайдерів,
формування контексту, структуровані відповіді,
облік використання AI та автоматизовані тести.

Підключення реальної моделі Gemini перевірено
на п'яти тестових запитах.

Результат перевірки: 5 успішних запитів із 5.
Середній час відповіді: 3.494 секунди.

Детальні результати наведено в документі
`docs/measurements.md`.

## 10. Подальший розвиток

Планується вдосконалення якості шахових пояснень,
розширення набору тестових прикладів, покращення
обробки помилок і дослідження можливостей
персоналізованого навчання.
