# ADR 003. Вибір AI-провайдера

## Контекст

ChessMind використовуватиме AI-помічника, який пояснюватиме шахові правила, відповідатиме на запитання користувача та надаватиме підказки під час гри.

Для цього потрібно підключити мовну модель. Однак на початковому етапі важливо мати можливість перевіряти роботу застосунку без використання платних AI-сервісів.

## Рішення

Для початкової версії обрано mock-провайдер, який імітує роботу мовної моделі та повертає заздалегідь визначені структуровані відповіді.

У програмі буде створено спільний інтерфейс для AI-провайдерів. Це дозволить у майбутньому підключити справжню мовну модель без зміни основної логіки застосунку.

Для пояснення шахових позицій планується використовувати мовну модель Gemini або іншу сумісну модель.

Stockfish відповідатиме за аналіз шахових позицій, пошук сильних ходів та виявлення помилок. Він не замінюватиме мовну модель, а надаватиме їй шахову інформацію для пояснення користувачеві.

## Наслідки

Використання mock-провайдера дозволяє тестувати роботу AI-помічника без API-ключів та додаткових витрат.

Завдяки спільному інтерфейсу можна буде замінити тестовий провайдер на справжню мовну модель без переписування основної частини програми.

Окреме використання шахового рушія та мовної моделі дозволяє правильно розподілити їхні завдання.
