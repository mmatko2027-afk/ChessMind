# ADR 002. Вибір сховища даних

## Контекст

ChessMind повинен зберігати інформацію про шахові партії, налаштування користувачів та результати аналізу. Тому застосунку потрібне сховище даних.

## Рішення

Для початкової версії проєкту обрано SQLite.

База даних використовуватиметься для збереження:
- налаштувань користувача;
- обраного рівня складності;
- вигляду та розташування AI-помічника;
- історії шахових партій;
- результатів аналізу.

Взаємодія із базою даних буде реалізована через окремий модуль storage.py.

## Наслідки

SQLite не потребує встановлення окремого сервера бази даних і підходить для розробки та тестування початкової версії ChessMind.

У майбутньому, якщо кількість користувачів збільшиться, можна буде перейти на PostgreSQL без значної зміни решти програми, якщо зберегти окремий модуль роботи з даними.
