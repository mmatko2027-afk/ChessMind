# ADR 001. Вибір синхронного та фонового виконання операцій

## Контекст

У ChessMind передбачені операції, які відрізняються за тривалістю виконання. Наприклад, відповідь AI-помічника потрібна користувачеві під час гри, а аналіз усієї шахової партії може займати більше часу.

## Рішення

Для коротких операцій використовується синхронне виконання. Сервер одразу повертає результат запиту.

До таких операцій належать:
- отримання пояснення від AI-помічника;
- перевірка шахового ходу;
- отримання поточного стану партії.

Для тривалих операцій використовується фонове виконання. Наприклад, аналіз завершеної шахової партії.

Сервер повертає ідентифікатор завдання та його початковий статус. Користувач може окремо перевірити стан виконання та отримати результат.

## Наслідки

Такий підхід дозволяє не змушувати користувача довго чекати на відповідь сервера. Також він дає можливість виконувати складний аналіз партії окремо від основної роботи застосунку.
