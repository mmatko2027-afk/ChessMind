# ChessMind — інтелектуальний шаховий тренер

## 1. Опис проєкту

ChessMind — це вебзастосунок для навчання шахів, гри проти комп'ютерного суперника та аналізу завершених шахових партій із використанням штучного інтелекту.

Основна мета проєкту — допомогти користувачам різного рівня підготовки покращувати свої шахові навички, розуміти причини помилок і навчатися приймати кращі рішення під час гри.

У проєкті поєднуються два AI-компоненти:

- Stockfish — спеціалізований шаховий рушій для аналізу позицій, пошуку найкращих ходів та оцінювання шахових ситуацій.
- Мовна модель через Gemini API — для пояснення шахових ситуацій, надання підказок і формування рекомендацій українською мовою.

## 2. Основні можливості

- Інтерактивна шахова дошка.
- Перевірка допустимості шахових ходів.
- Навчання з підказками.
- Гра проти комп'ютерного суперника.
- Аналіз шахових позицій.
- Пояснення найкращих ходів, помилок і неточностей.
- Аналіз завершених партій.
- Завантаження партій у форматі PGN.
- Формування рекомендацій для покращення гри.

## 3. Рівні користувача

У ChessMind передбачено три рівні підготовки:

1. Початківець — пояснення правил, підписи назв фігур і підказки під час гри.
2. Середній рівень — самостійна гра, підказки щодо кращих ходів і пояснення помилок.
3. Досвідчений гравець — поглиблений аналіз позицій, оцінювання ходів і детальні рекомендації.

Користувач самостійно обирає рівень та може змінювати його в налаштуваннях.

## 4. Технології

| Технологія | Призначення |
|---|---|
| Python | Основна мова програмування |
| FastAPI | Серверна частина |
| HTML | Структура вебсторінок |
| CSS | Оформлення інтерфейсу |
| JavaScript | Інтерактивність шахової дошки |
| python-chess | Робота з шаховими правилами та партіями |
| Stockfish | Шаховий аналіз |
| Gemini API | Мовні пояснення та рекомендації |

## 5. Принцип роботи

1. Користувач обирає рівень підготовки та режим роботи.
2. Застосунок відображає шахову дошку.
3. Програмний код і python-chess перевіряють допустимість ходів.
4. Stockfish виконує шаховий аналіз за потреби.
5. Результати аналізу передаються мовній моделі.
6. Мовна модель формує пояснення відповідно до рівня користувача.
7. Після завершення партії користувач отримує результати аналізу та рекомендації.

## 7. План розробки

Розробка проєкту розрахована на 7 тижнів:

- Підготовка проєкту та налаштування середовища.
- Створення шахової дошки та реалізація правил гри.
- Інтеграція Stockfish.
- Підключення мовної моделі.
- Реалізація рівнів користувача та режимів роботи.
- Аналіз партій і перевірка якості.
- Тестування та підготовка завершеної версії.

Детальний план наведено у файлі `docs/backlog.md`.

## 8. Тестування

Для перевірки якості роботи ChessMind підготовлено тестові приклади у файлі `eval/cases.json`.

Вони охоплюють пояснення шахових правил, аналіз ходів, пошук помилок, надання підказок та обробку помилок AI-компонентів.
