
# ChessMind

ChessMind — інтелектуальний шаховий помічник, який допомагає користувачам вивчати шахи, розуміти правила та отримувати пояснення шахових понять за допомогою штучного інтелекту.

## Мета проєкту

Мета проєкту — створити програмну систему, яка приймає запитання користувача, формує контекст і передає його AI-моделі для отримання зрозумілої відповіді.

## Можливості

- Пояснення шахових правил і понять.
- Обробка запитань через REST API.
- Формування контексту для AI-моделі.
- Підтримка декількох AI-провайдерів.
- Структуровані відповіді у форматі JSON.
- Перевірка отриманих відповідей.
- Обробка помилок і повторні спроби.
- Облік використання токенів.
- Контроль денного бюджету та кількості запитів.
- Збереження статистики у SQLite.

## Встановлення

Потрібно мати встановлений Python 3.13 або сумісну версію.

Клонування репозиторію:

```powershell
git clone https://github.com/mmatko2027-afk/ChessMind.git
cd ChessMind
```

Створення віртуального середовища:

```powershell
python -m venv .venv
```

Активація:

```powershell
.venv\Scripts\Activate.ps1
```

Встановлення залежностей:

```powershell
pip install -r requirements.txt
```

## Налаштування

Створіть файл `.env` на основі `.env.example`.

У ньому можна налаштувати:

- AI-провайдера;
- назву моделі;
- API-ключ;
- адресу API;
- час очікування відповіді;
- ліміт запитів;
- денний бюджет;
- шлях до бази даних.

Для роботи з реальною моделлю Gemini потрібно вказати власний API-ключ.

Не публікуйте файл `.env` і не додавайте API-ключ до GitHub.

## Запуск

Запуск сервера:

```powershell
uvicorn app.main:app --reload
```

Після запуску API буде доступне за адресою:

```text
http://127.0.0.1:8000
```

Інтерактивна документація API:

```text
http://127.0.0.1:8000/docs
```

## Тестування

Для запуску автоматизованих тестів:

```powershell
python -m pytest -v
```

## Перевірка AI-моделі

Для окремої перевірки підключення Gemini використовується:

```powershell
python check_gemini.py
```

Під час тестування моделі `gemini-3.1-flash-lite` було виконано п'ять запитів.

Результат:

- Успішні запити: 5 із 5.
- Середній час відповіді: 3.494 секунди.
- Загальна кількість токенів: 2378.

Детальні результати наведено у файлі `docs/measurements.md`.

## Обмеження

ChessMind призначений для навчання шахів і пояснення шахових понять.

AI-модель може помилятися, тому її відповіді не слід вважати гарантовано правильними. Для перевірки легальності ходів і точного аналізу позицій у майбутньому може бути інтегрований спеціалізований шаховий рушій.
